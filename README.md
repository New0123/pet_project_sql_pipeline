Задано: Sql скрипты для Greenplum которые нужно выполнить последовательно согласно их порядковому номеру.
Последующий скрипт выполняется только тогда, когда успешно закончено выполнение предыдущего.
Реализация:
Простой аналог pipeline для последовательного выполнения sql скриптов.
В случае ошибки - прекращение работы.
Последовательно выполняет *.sql из sql_pipeline
предварительно подставляя параметры :name из param.txt и пишет статистику выполнения и ошибки в resume_exec.txt
